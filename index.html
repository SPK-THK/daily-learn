📖 使用教程

  1. 📈 看一眼自选行情进入「股票」页点「刷新」，红涨绿跌一目了然；当日刷新一次即完成「复盘自选股」打卡。
  2. 📖 完成今日单词「英语 → 背单词」：看卡片 → 显示答案 → 如实选择「记住了 / 又忘了」。系统按遗忘曲线（1/2/4/7/15 天）安排复习，翻面后还有常用搭配和记忆点。
  3. 🎧 练一轮听写「英语 → 听写」：看中文或听发音拼单词，每轮 10 题；答错的词进错词本，可以随时专项复习。
  4. 📰 读一篇双语短文「英语 → 双语阅读」读今日推荐：段落对照翻译，点词汇可发音，文末有语法讲解，读完标记已读。

🎯 打卡规则：今日三项全部完成 = 打卡成功，连续天数持续累积。

🏅 查看成长：「统计」页有 8 周打卡日历、词汇分布和成就墙，记录越多，颜色越深。

🎓 进阶课程：「股票 → 入门教程」有 12 节零基础课（正文 + 要点 + 小测验），每天一节更健康。

🎧 听写与错词本：「英语 → 听写」可看中文或听发音拼单词，每轮 10 题；答错的词会自动进「错词本」，按错误次数排序，支持一键听写复习。

🌙 深色模式：右上角 / 侧栏的主题按钮可在「跟随系统 / 浅色 / 深色」间切换，选择会记住。

🔊 发音：单词、词组、金句、词汇表都可点击喇叭朗读（需要浏览器支持语音）。

💾 数据说明：所有学习记录保存在本机浏览器，无需注册登录；换设备可用下方按钮迁移。

📦 数据导出 / 导入

导出为 JSON 备份文件；导入会合并到当前记录（同名键以导入为准），不会清空现有数据。

📲 下载 / 安装到手机

装到主屏幕后，电脑关机、断网也能打开；学习记录仍然只保存在本机。

  1. iPhone / iPad用 Safari 打开，点底部「分享」→「添加到主屏幕」。
  2. Android用 Chrome 打开，点右上角 ⋮ →「安装应用」或「添加到主屏幕」。
  3. 电脑打开下面地址，用手机扫码或把链接发到手机。
