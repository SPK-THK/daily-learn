# 每日进化 · 英语 × 股票（离线 PWA）

手机打开：<https://spk-thk.github.io/daily-learn/>

## 安装到手机

**iPhone / Safari**（必须用 Safari，不要在微信里打开）：

1. 打开上面的地址，等页面完全加载；
2. 点底部「分享」→「添加到主屏幕」；
3. 之后从主屏幕打开即可。

**Android / Chrome**：

1. 打开上面的地址，等页面完全加载；
2. 右上角「⋮」→「添加到主屏幕 / 安装应用」；
3. 之后从桌面图标打开。

首次打开需要联网；页面加载后 Service Worker 会自动缓存，**之后断网、电脑关机也能打开**。

## 能离线用什么

- 离线可用：打卡、背单词、双语阅读、每日一句、词库、学习统计、数据导入导出
- 需要联网：A股行情与 K 线（手机直连腾讯行情，不经过电脑）
- 学习记录只保存在本机浏览器 localStorage，不上传服务器；换设备用「使用教程 → 导出/导入」迁移
