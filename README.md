# 每日进化 · 英语 × 股票（离线 PWA）

手机打开：<https://spk-thk.github.io/daily-learn/>

- 打卡 + 背单词（艾宾浩斯 SRS）+ 双语阅读 + 每日一句 + A股自选行情 + 学习统计
- 首次打开后由 Service Worker 缓存，**电脑关机 / 断网也能用**；行情在有网时由手机直连腾讯行情
- 学习记录只保存在本机浏览器 localStorage，不上传服务器
- 添加到主屏幕：iPhone Safari「分享 → 添加到主屏幕」；Android Chrome「⋮ → 添加到主屏幕 / 安装应用」

本仓库是构建产物（`index.html` + 打包后的 `app.js` + Service Worker），源码不在此仓库。
