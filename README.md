# 每日进化 · 英语 × 股票（离线 PWA）

手机打开：<https://spk-thk.github.io/daily-learn/>

## 功能

- 每日打卡、连续天数、成就
- 背单词（艾宾浩斯）、双语阅读、每日一句（本地音频 + 下载）、词库
- A股自选行情、K 线、股票课程（按基础/看盘/基本面/交易分类）
- 财经快讯：宏观 / 公司 / 全球 / 市场分类 + 应用内全文阅读
- 学习统计、数据导出/导入、底部版本号
- 页面顶部 / 侧边栏「⬇ 下载」按钮：一键安装到主屏幕

## 安装到手机

**iPhone / Safari**（必须用 Safari，不要在微信里打开）：

1. 打开上面的地址，等页面完全加载；
2. 点底部「分享」→「添加到主屏幕」；
3. 之后从主屏幕打开即可。

**Android / Chrome**：

1. 打开上面的地址，等页面完全加载；
2. 右上角「⋮」→「添加到主屏幕 / 安装应用」；
3. 之后从桌面图标打开。

首次打开需要联网；页面加载后 Service Worker 会自动缓存，**之后断网、电脑关机也能打开**。

## 能离线用什么

- 离线可用：打卡、背单词、双语阅读、每日一句、词库、学习统计、资讯缓存（含正文）、数据导入导出
- 需要联网：A股行情与 K 线、最新财经快讯（手机直连行情/读取新闻快照，不经过电脑）
- 学习记录只保存在本机浏览器 localStorage，不上传服务器；换设备用「使用教程 → 导出/导入」迁移

## 数据是怎么更新的

- **行情**：交易时段每 60 秒自动刷新一次；非交易时段显示最近收盘数据
- **财经快讯**：GitHub Actions 每小时抓取一次东方财富 7×24 快讯并更新 `news.json`；打开资讯页时也会拉取最新快照，离线显示上次缓存
- **学习内容**：词库、文章、金句、课程是内置内容，不会每天自动新增；系统按日期轮换“今日单词 / 今日推荐 / 每日一句”
- **打卡与统计**：根据你每天的操作实时计算

## 平板与发音

- iPad / Android 平板打开同一个地址即可，布局会自动切换为侧边栏 + 宽屏网格（今日页三栏、本周节奏、今日金句）
- 发音优先使用在线词典音频（需联网）；断网时回退系统英文语音
- 如果没有声音：先检查媒体音量和网络；系统里最好安装一个英文语音包（设置 → 无障碍/语音 → 文字转语音）
